# QuickFork Compact Infographic SaaS Stitch Prompt

Create a precise, compact SaaS landing page for QuickFork, a repo-to-infographic tool that helps developers cold-start and distribute public projects.

**Core product sentence:** Repo in. Infographic out.

**Required page behavior:**
- First viewport must show the actual generator: GitHub repo URL input, Generate package button, language toggles, and ratio selector.
- Right side must show generated results only: infographic preview, compact output format stack, and a simple Repo -> Infographic -> Share pipeline.
- Product animation belongs in a separate demo section below the Hero.
- Header must be short: QuickFork, Features dropdown, Studio, Examples, Resources, Pricing, Sign in, and Sign up. Account CTAs are allowed; product or function CTAs are not allowed in the Header.
- Feature section must use three compact steps: Repo, Infographic, Distribute.
- Workflow section must use three compact lanes: Input, Generate, Export.

**Visual system:**
- White workspace, crisp hairline borders, dark navy primary action, Product Green (#178f74) for pipeline state.
- Typography uses the existing QuickFork sans for headings and mono labels for chips, stages, and metadata.
- Cards should be functional repeated items only. No nested cards.

**Avoid:**
- No command-center metaphor.
- No dense evidence diagrams.
- No heavy output queue narrative.
- No fake metrics or social proof.
- No verbose hero copy.
- No decorative gradient hero.

**Target visual result:**
The page should look like a simple developer SaaS tool where one repo URL becomes a README-ready infographic and social distribution package.
