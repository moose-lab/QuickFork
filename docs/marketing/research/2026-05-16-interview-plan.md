# QuickFork User Interview Plan

*Generated: 2026-05-16*

## Goal

Validate whether target users value QuickFork as a source-backed GitHub repo-to-launch package workflow, not only as a README image or AI copy generator.

## Required Sample

| Segment | Minimum | Recruit criteria |
| --- | ---: | --- |
| Open-source maintainers | 5 | Has launched or promoted a public GitHub repo in the last 6 months |
| Indie/devtool founders | 5 | Has shared a tool on Product Hunt, Hacker News, Reddit, X, or LinkedIn |
| DevRel/product marketers | 3 | Has packaged technical projects for public distribution |

## Session Format

Length: 30 minutes.

Required artifact: a real public GitHub repository chosen by the participant.

Flow:

1. Ask about the last time they promoted a GitHub project.
2. Ask what assets they had to create.
3. Ask what they avoided because it felt too time-consuming or too promotional.
4. Ask them to paste a real repo into QuickFork.
5. Observe whether they hesitate before generation.
6. Ask what they inspect first after generation.
7. Ask whether they trust the generated claims and visuals.
8. Ask whether they would download, edit, share, or publish the result.
9. Ask them to compare QuickFork to their current workaround.

## Core Questions

### Trigger

- What made you decide this repo needed public launch or promotion?
- Where did you share it first?
- What did you wish you had prepared before launch?

### Current Alternatives

- What did you use for README visuals, social previews, or launch posts?
- Did you use ChatGPT, Canva, Figma, Socialify, README generators, or manual writing?
- What worked and what felt painful?

### Trust

- What would make you distrust an AI-generated launch asset?
- Would a source-backed brief or QA report change that?
- How important are "no invented metrics" and "no random logos"?

### Artifact Value

- Which output matters most: generated image, curated brief, localized copy, prompt, quality report, or manifest?
- Which output would you actually use this week?
- Would you publish a public showcase page, or only download private assets?

### Customer Language

- How would you describe the problem QuickFork solves in your own words?
- What phrase would you search for if you needed this?
- What wording sounds too much like marketing or spam?

## Completion Gate

Do not update final positioning until:

- 13+ interviews are complete.
- At least 3 segments are represented.
- The same primary job appears across 3+ independent participants.
- At least one objection repeats across 3+ participants.
- At least one artifact-value ranking pattern is clear.
