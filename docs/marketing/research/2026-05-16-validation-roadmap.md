3. **Interview:** target users generate a real card and explain trust/friction.
4. **Smoke test:** publish minimal pages for category, trust, utility, and examples.
5. **Compare:** users compare QuickFork with Socialify, README generators, ChatGPT, and manual design.
6. **Experiment:** test the highest-risk positioning and trust hypotheses.
7. **Codify:** update product marketing context with confirmed language, rejected language, and proven channels.
